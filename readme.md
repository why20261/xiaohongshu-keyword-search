## 1. 技能概述

这是一款专注于**小红书数据获取**的工具。它能够穿透小红书的公开数据层，为你提供深度的**竞品监控**、**趋势预测**和**KOL 筛选**服务。无论你是内容创作者、品牌营销人员还是市场分析师，都能通过此工具获取决策支持。

**🔥核心优势**

> - 安全: 无需登录小红书账号，规避账号风控、封号风险（不用准备爬虫小号）
> - 强大: 单次最多获取 10000 条笔记数据，快速完成赛道批量调研
> - 全面: 返回页面可见全部公开字段，拿来直接做分析报告
> - 灵活: 支持多维度筛选（时间、点赞排序等）快速定位爆款 / 最新笔记
> - 轻量: 无需部署服务，本地 Node.js 一键运行
> - 实用: 自动归档运行日志，便于复盘，适配营销报告、内容策划场景

## 5. ❓ FAQ和技术说明

### 5.1 运行环境兼容说明

- 系统兼容：Windows/Linux/MacOS（无需额外依赖，仅需Node.js）
- Node.js版本：推荐16.14.0+
- 网络要求：需能正常访问网络，国内服务器无需代理
- 权限要求：无需管理员权限，普通用户即可运行

### 5.2 常见问题

1. Q：是否需要小红书账号？A：不需要登录小红书账号，仅使用 API Token。
2. Q：数据是实时的吗？A：数据为接口拉取时的公开快照，存在少量延迟。
3. Q：我可以把采集到的数据对外售卖分发吗？A：仅限个人 / 团队内部分析使用，禁止对外分发。
4. Q：支持导出 CSV 表格吗？A：可基于返回数据自行导出，参考 `references/options.md` 配置输出格式。

### 5.3 日志说明

- 启动时会打印工具Banner，方便确认是否正确执行；
- 过程中会输出彩色日志，用于反馈技能执行情况，过程中无需用户交互；
